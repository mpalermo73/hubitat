# Hubitat apps and drivers

| Package | Description |
|---|---|
| [MyFuelPortal](myfuelportal/) | Propane/fuel tank level, usage estimate and account info from MyFuelPortal providers (e.g. Heller's Gas). |

Install with [Hubitat Package Manager](https://hubitatpackagemanager.hubitatcommunity.com/): search for the package name, or **Install** > **From a URL** with the package's `packageManifest.json` raw URL.
